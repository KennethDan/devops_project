# DevOps Project - Week 1

## Introduction
This repository contains my first-week DevOps
practical assignment.

The project demonstrates my understanding of:
- Linux commands
- Bash scripting
- Git and GitHub
- SSH connections
- Basic project directory management

## Project Files

- hello.sh: Displays a welcome message.
- project-structure.sh: Creates the project directory structure.
- scripts/: Contains supporting scripts.
- docs/: Contains project documentation.
- logs/: Stores project log files.

## How to Run

First, clone the repository:

git clone https://github.com/KennethDan/devops_project.git

Enter the project directory:

cd devops-project

Make the scripts executable:

chmod +x hello.sh project-structure.sh

Run the scripts:

./hello.sh
./project-structure.sh
